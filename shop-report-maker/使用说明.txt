  店铺报表自动化 v1.0 · 使用说明
═══════════════════════════════════════

【这个软件是干什么的】
把店铺后台导出的订单明细表，一键变成老板要看的销售报表：
总览数据 + 每日趋势图 + 商品排行 + 月度对比，全部自动算好、排好版。

【运行环境】
Windows 7 / 10 / 11（64位），双击 exe 即用，无需安装。

【三步上手】
① 选择订单表：把淘宝/拼多多/抖店/京东后台导出的订单明细 .xlsx/.csv 拖进来
   （支持一次多选，多个月份/多个平台的表会自动合并）
② 载入识别：软件自动识别「日期/商品/数量/金额」四列
   （不同平台列名不同也能认：订单日期/下单时间、实付金额/成交金额、宝贝标题/商品名称…）
   识别错了就在下拉框里手动改，改完点「生成报表」
③ 生成报表：自动在 exe 同目录「报表输出」文件夹生成 Excel 报表

【报表里有什么】
📊 总览         总销售额 / 总订单数 / 客单价 / 覆盖天数 / 日均销售额 / 总件数 / TOP1商品
📅 按日汇总     每日销售额、订单数、件数 + 折线趋势图
📦 按商品汇总   每个商品销售额、件数、订单数、销售额占比 + TOP10 柱状图
🗓 按月汇总     月度销售趋势（跨月数据自动分组）

【支持的列名（自动识别，不完全列举）】
日期：日期 / 下单时间 / 成交时间 / 付款时间 / 创建时间 / 订单日期
商品：商品 / 商品名称 / 宝贝标题 / 产品名称 / 品名 / 货品
数量：数量 / 购买数量 / 件数 / 销量
金额：金额 / 订单金额 / 成交金额 / 实付金额 / 销售额 / 总价

【常见问题】
Q: 我的列名不在上面怎么办？
A: 载入后手动在下拉框选对应列即可，软件按你选的算。
Q: 日期有的行解析不出来？
A: 会提示排除了几行，通常是该行日期为空或格式异常。
Q: 杀毒软件报毒？
A: PyInstaller 打包偶有误报，添加信任即可，源码可提供核验。
Q: 报表打不开/被占用？
A: 关掉已打开的 Excel 再生成。
