# 电商卖家工具族 ecom-tools

为中小电商卖家打造的免费桌面小工具合集。全部免安装、双击即用、本地运行（数据不出电脑）。

> Windows 7 / 10 / 11（64 位）· 免安装 · 单文件 · 无广告无弹窗

## 工具列表

| 工具 | 功能 | 适用场景 |
|------|------|----------|
| ⏰ 定时任务执行器 | 按设定间隔自动向指定网址发送 GET/POST 请求，支持失败重试、动态变量、全程日志 | 接口保活、数据轮询、自动签到、定时通知、挂机任务 |
| 🧹 数据清洗助手 | Excel/CSV 批量去重、删空值/填充、查找替换、去空格、多表合并 | 订单数据清洗、客户名单整理、多渠道数据合并 |
| 📊 店铺报表自动化 | 订单明细一键生成销售报表：总览+每日趋势+商品排行+月度对比，自带图表 | 淘宝/拼多多/抖店/京东卖家周报月报 |

## 快速开始

1. 到 [Releases](../../releases) 下载对应工具的 zip（或使用网盘备用链接）
2. 解压后双击 exe 即用，无需安装任何运行库
3. 压缩包内含《使用说明.txt》，每个功能都有截图说明

## 从源码运行

```bash
pip install -r requirements.txt
python 主程序.py
```
